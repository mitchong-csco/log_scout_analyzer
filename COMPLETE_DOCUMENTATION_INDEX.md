## 📌 Key Points from All Docs

**The Problem:**
- Message field was confusing (used "description" for template)
- System fallback to matched_text instead of using template

**The Solution:**
- Renamed field to "annotation" (semantic clarity)
- Template is required (not optional)
- Citation model: annotation ≠ log_line
- Structured parameters as list of {name, value}

**What Extension Gets:**
```json
{
  "message": "merged_template_value",
  "data": {
    "template": "raw {{ field }} template",
    "merged_template": "merged value",
    "log_line": "full original log line",
    "extracted_parameters": [{name, value}, ...],
    // ... all metadata
  }
}
```

**Design Philosophy:**
> "If you can't document it, it never happened" + "Trust but verify"
- Document = Template
- Verify = Log line
- Always show both
