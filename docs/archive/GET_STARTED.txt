QUICK START (Choose your OS):
------------------------------

WINDOWS:
  build.bat          # Build everything and install
  
MAC/LINUX:
  ./build.sh         # Build everything and install

STEP BY STEP:
-------------

1. Install Rust (if not already installed)
   Windows: build.bat setup
   Mac/Linux: ./build.sh setup

2. Build the extension
   Windows: build.bat build
   Mac/Linux: ./build.sh build

3. Run tests
   Windows: build.bat test
   Mac/Linux: ./build.sh test

4. Install to Zed
   Windows: build.bat install
   Mac/Linux: ./build.sh install

5. Restart Zed editor

6. Open examples/sample.log to see it in action!
