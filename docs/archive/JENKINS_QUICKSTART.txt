SUPER EASY METHOD (Recommended):
══════════════════════════════════════════════════════════

1. Make sure Docker is installed and running
   - Windows: Download from docker.com
   - Mac: Download Docker Desktop
   - Linux: sudo apt install docker.io docker-compose

2. Run ONE command:
   
   ./jenkins-quick-start.sh

3. Open browser to: http://localhost:8080

4. Log in with the password shown in terminal

5. Click "Build Now" - Jenkins builds everything for you!

AFTER JENKINS BUILDS:
══════════════════════════════════════════════════════════

5. Extract and install to Zed

TROUBLESHOOTING:
══════════════════════════════════════════════════════════

Problem: Docker not running
Solution: Start Docker Desktop

Problem: Port 8080 in use
Solution: Edit docker-compose.yml, change "8080:8080" to "8081:8080"

Problem: Build fails
Solution: Check Jenkins logs with: ./jenkins-quick-start.sh logs
