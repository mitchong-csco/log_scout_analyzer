══════════════════════════════════════════════════════════
SUPER EASY SETUP (3 STEPS):
══════════════════════════════════════════════════════════

1. Install Podman:
   Windows:  winget install RedHat.Podman
   Mac:      brew install podman
   Linux:    sudo apt install podman

2. Run ONE command:
   ./jenkins-quick-start.sh

3. Open browser:
   http://localhost:8080

That's it! Jenkins + Podman builds everything for you! 🎉

══════════════════════════════════════════════════════════
MAC/WINDOWS SPECIFIC:
══════════════════════════════════════════════════════════

# Podman needs a machine on Mac/Windows
podman machine init          - Create machine
podman machine start         - Start machine
podman machine stop          - Stop machine
podman machine list          - List machines

# Or use the script:
./jenkins-quick-start.sh machine-start
./jenkins-quick-start.sh machine-stop

TROUBLESHOOTING:
══════════════════════════════════════════════════════════

Problem: Podman not found
Solution: Add to PATH or reinstall

Problem: Permission denied
Solution: Run without sudo (rootless mode)
         or: sudo podman-compose up -d

Problem: Port 8080 in use
Solution: Edit podman-compose.yml
         Change "8080:8080" to "8081:8080"

Problem: Machine not starting (Mac/Windows)
Solution: podman machine rm podman-machine-default
         podman machine init
         podman machine start

══════════════════════════════════════════════════════════
PODMAN VS DOCKER:
══════════════════════════════════════════════════════════

All Docker commands work with Podman!
Just replace "docker" with "podman":

docker ps      →  podman ps
docker run     →  podman run
docker logs    →  podman logs

Optional: Create alias
  alias docker=podman
  alias docker-compose=podman-compose
